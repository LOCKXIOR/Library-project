# Library Project
A small Python library system I made in December 2025.

## About this project — December 2025
This is one of my early Python projects. I decided to publish it as-is because
it reflects my real learning process at the time. The code is not perfect, but
it shows how I was experimenting with functions, dictionaries, menus, and basic
program logic.

I had fun adding humor in the messages, creating an admin mode, a password
system, and a small interactive menu. It was one of my first “big” Python
projects.

## What this project represents
I didn’t really learn something new while making this — I mostly applied what I
already knew in Python. It helped me understand how to structure a program and
how to manipulate nested dictionaries.

- Add try/except to avoid crashes
- Clean up the menu system
- Fix the title search function

- Add a Tkinter interface

# Library Project — UI Version (Untitled-10)
A Tkinter-based graphical version of my early Python library system.

## About this project — Late 2025 / Early 2026
This is the graphical version of my Library Project. I made it shortly after
the console version, when I started experimenting with Tkinter and graphical
interfaces in Python.

The project includes:
- A main window
- Buttons that appear and disappear
- A simple admin mode with password
- A small library dictionary
- Message boxes for errors and confirmations
- A click counter (with a surprise at 67 clicks)
- Multiple windows interacting together

I decided to publish this project as-is because it reflects my real learning
process at the time. The code is not perfect, but it shows how I was exploring
UI programming and having fun with Python.

## What this project represents
I didn’t really “learn” something new while making this — I mostly applied what
I already knew and tried to understand how Tkinter works. It helped me discover
event-driven programming and how to manage widgets dynamically.

## Future improvements (Maybe)
- Clean up the admin password system
- Add real library interactions (borrow, return, search)
- Improve the UI layout
- Add JSON saving/loading
- Add a dark mode
