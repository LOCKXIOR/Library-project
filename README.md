# Library Project
A small Python library system I made in December 2025.

## About this project — December 2025
This is one of my early Python projects. I decided to publish it as-is because
it reflects my real learning process at the time. The code is not perfect, but
it shows how I was experimenting with functions, dictionaries, menus, and basic
program logic.

I had fun adding humor in the messages, creating an admin mode, a password
system, and a small interactive menu. It was one of my first “big” Python
projects.

## What this project represents
I didn’t really learn something new while making this — I mostly applied what I
already knew in Python. It helped me understand how to structure a program and
how to manipulate nested dictionaries.
